Fly Learning Lab

A fly-inspired learning research prototype for running controlled synthetic experiments and exploring their results in a dashboard.
AI / RESEARCH SOFTWARERESEARCH PROTOTYPE

Research software & experiment development · Python · Machine learning · Research · Dashboard

The challenge

Compare learning and transfer under controlled conditions while keeping experiments reproducible and results clear about their limitations.

What I built

Built a Python learning core, experiment controls, checkpoint recovery, a worker, and a dashboard for monitoring research runs.

Results & verification

A 512-model synthetic odor-association run recorded 97.6% accuracy versus 50.1% with frozen weights. A follow-up with 192 pretrained and naive model pairs found no learning advantage from pretraining. These are synthetic experiments, not measurements of biological flies.

Technical notes

  • Configurable experiments compare learning against frozen-weight controls.
  • A separate Python worker runs jobs, saves checkpoints, and reports progress to a private dashboard.
  • Reports document replication results, limitations, and the distinction between synthetic models and measured connectomes.

FineTune Lab

A local experiment studio for training real LoRA adapters, inspecting loss curves, and comparing an adapted language model against its original outputs.
MACHINE LEARNING / MODEL TRAININGLOCAL TRAINING VERIFIED

ML training, evaluation & application development · Python · PyTorch · LoRA / PEFT · FastAPI

The challenge

Demonstrate actual model adaptation and reproducible evaluation without confusing lower training loss or better JSON formatting with better task accuracy.

What I built

Built a FastAPI experiment app, an explicit PyTorch training loop, PEFT LoRA adapters, immutable dataset snapshots, and strict held-out scoring with exportable run artifacts.

Results & verification

Completed real CPU training and saved-adapter inference with 22 tests passing. A recorded 40-step run trained 460,800 adapter parameters and produced valid JSON on all eight synthetic test examples. Exact label matches were only 2/8, equal to a trivial baseline, so the result demonstrates a working training pipeline rather than a useful classifier.

Technical notes

  • SmolLM2-135M stays frozen while rank-8 LoRA matrices train on response tokens only.
  • Dataset fingerprints and separate train, validation, and test splits make each run inspectable; invalid predictions count as incorrect.
  • Saved adapters reload in a separate process, and exports include weights, tokenizer, data, configuration, and measured results.

APPLIED AI / INCIDENT INVESTIGATIONLOCAL INFERENCE VERIFIED

Hybrid retrieval & local inference engineering · Python · Hybrid retrieval · Local LLMs · SQLite

The challenge

Find relevant operational evidence and preserve its provenance while making missing citations, rejected model outputs, and retrieval tradeoffs visible.

What I built

Built BM25 and dense retrieval, reciprocal-rank fusion, cross-encoder reranking, local Qwen inference, and persistent investigations with line-level source snapshots.

Results & verification

Verified real embedding, reranking, and local generation with 21 tests passing. A benchmark compares four retrieval methods on 15 synthetic questions and 12 runbooks. Technical notes

  • MiniLM embeddings complement lexical matching; rank fusion and reranking can be compared against each retrieval baseline.
  • Runbook excerpts retain source lines, while event IDs, model revisions, and index fingerprints travel with exported investigations.
  • FastAPI and SQLite preserve runbooks and investigation history; local Qwen3 drafts are checked for missing citations and truncated output.

Recoverable Firmware Updater

An A/B firmware updater that keeps a working application while staging a new version, with recovery paths validated in a persistent flash simulator.
EMBEDDED / BOOTLOADERSHOST VERIFIED

Embedded firmware & tooling · C · Python · STM32 · Bootloaders

The challenge

Recover safely when an update is interrupted or a trial application fails to confirm, without losing the last working firmware.

What I built

Built a portable C bootloader core, Python update tools, a framed UART protocol, and an STM32F401RE reference port.

Results & verification

Validated update, confirmation, and rollback paths in a persistent C simulator. Separate fault-injection tests passed 53,309 modeled flash-interruption positions. All four CI jobs passed, covering host tests, sanitizers, and ARM cross-builds. Physical STM32 testing is the next step.

Technical notes

  • Inactive-slot staging preserves the confirmed application. An unconfirmed trial rolls back on the next reset.
  • Alternating metadata sectors use CRC32 and a commit marker written last to detect interrupted writes.
  • Linux and macOS host checks pass, and GNU Arm builds link the bootloader and both application slots.

The challenge

Process quotes from two simulated venues while handling invalid packets, sequence gaps, trading limits, and downstream stalls.

What I built

Built PCAP decoding, feed validation, and quote-processing logic in C++20, alongside a SystemVerilog decision and risk pipeline.

Results & verification

  • Quote comparison feeds order-size, order-value, and position checks, with a kill switch.
  • RTL simulations exercise the decision pipeline with downstream stalls and check its four-cycle latency when unstalled.
